## 使用心法三句话

1. **入口用第一性原理，聚焦用单点破局**——先想清楚本质，再把资源压到一个尖点；顺序反了就是「用战术勤奋掩盖战略懒惰」。
2. **过程用数据驱动兜底**——所有武器都可能失灵，唯独「假设-度量-修正」的反馈环永远有效；AI 产品尤其要用评测数据代替主观判断。
3. **长期用一思维校准**——每季度重问 What/Why/How：模型技术在变，产品的「一」变没变？变则破界创新，不变则长期主义。

## 13 张技能卡（三门课蒸馏，五层安全扫描通过）

| 卡 | 一句话 | 关键内容 |
|---|--------|---------|
| **业务留档** | AI 无法进入公司时让它理解并操作业务 | 五步：过程存档留痕（录音/文档/埋点）→ 梳理业务实体/关系/动作 → 建本体论或知识图谱 → 系统 CLI 化 → 建 MCP 写 AI 说明书。YC 用 Office Hour 录音生成创业手册 |
| 区分事实与趋势 | 已发生的突破 ≠ 未来趋势 | 识别已发生的技术突破 → 分析影响 → 区分短期可执行与长期不确定 → 按企业阶段定策略（2022 ChatGPT / 2024 Claude Code 是事实，具身机器人是趋势） |
| 分圈作战 | 小团队端到端闭环 | 端到端负责 · 高内聚低耦合 · 独立决策权 · 紧缩预算+超量授权 · 圈间技能共享（安克组织专小化四步） |
| 对齐事实 | 让所有人看到同一张地图 | 同一共享对象 · 同一事实源 · AI 替代人工传递 · 规范嵌入系统自动执行 · 用原型讨论而非语言（波音统一数字设计）＝缝合怪律二同源 |
| 推进工作 | 让工作自己往前走 | AI 发现（问题自己举手）→ 分配（工作找人）→ 传导（自动交接）→ 检查（门禁+对抗）→ 复盘沉淀（海底捞自动派活）＝缝合怪推进四件事同源 |
| 人才大于岗位 | 关注通用素质而非岗位标准化 | 识别不可替代的非标判断 · 招底层素质 · 培养举一反三 |
| 团队大于组织 | 小团队协作 > 层级结构 | 直接管理 · 建设性冲突 · 自下而上领导力（皮克斯） |
| 形态大于结构 | 组织保持流变性 | 信息流通 · 多元涌现 · 张力优先于秩序（DeepSeek） |
| 超级个体 | 识别培养 AI 时代人才 | 老板带头 · 找自费买 AI 工具的员工 · 一对一辅导 · 专人解难 · 内部竞赛（鹿客） |
| 品牌实体构建 | 品牌信息一致性 | 权威源 · 统一名称属性 · 品牌知识库 |
| 多渠道发布 | AI 信任渠道发结构化内容 | 数字门牌 · 及时更新 · 全渠道一致 |
| 智能内容生成 | 生成 AI 可读内容 | 用户画像 → 结构化事实内容 → 多渠道发布 → 智能评估 |
| 用户问题导向 | 按真实问题优化内容 | 问题扩展模拟提问 → 监测 AI 问答 → 优化可见性排名（GEO/答案引擎优化四卡之一） |
