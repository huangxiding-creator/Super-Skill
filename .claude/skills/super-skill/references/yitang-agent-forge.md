# 训虾派 · AI 角色配置工程（一堂龙虾实践 2）

> 来源：一堂（CEO 初曼）《龙虾实践2：训虾派方法论与灵魂赋能体系》音频转录深度笔记（2026-03-25，`E:\AI-Station\04 智库\一堂\一堂龙虾实践2-深度笔记.md` 就地精读，语料本体永不入库）。"龙虾" = 一堂基于 Claude 系的 AI 员工产品；本文只萃取对 AI 产品开发者可迁移的**角色配置工程**方法，产品细节（Soul Builder 动画等）不入库。
> 加载时机：**Phase 8（多 agent / subagent 角色配置）· Phase 3（CLAUDE.md / 知识库 = 角色底座）· 任何"造 AI 角色 / 数字分身 / AI 团队"类裁决**。
> 定位：**角色配置工程层**——[renxin-ai-product-methodology](renxin-ai-product-methodology.md) 说"你掌握的所有方法论都应有一个 agent"（为什么造），本文管"怎么把 agent 快速配置到专家水平"（怎么造）；[ai-native-coordination](ai-native-coordination.md) 管多角色怎么协作运转，本文管单个角色怎么生产。

## 一句话总纲

**AI 角色的能力上限 = 配置文档水平**——不零散磨合"养"角色（养虾派），用系统工程一次性"训"到位（训虾派）：高价值输入 × 处理建模 × 集中产出 1000~3000 字配置（5~7 个文档），新角色 5~10 分钟上岗（一堂口径：5 分钟超过业内 99% 同类角色）。

## 三流派诊断（先判断自己在哪个流派）

| 流派 | 做法 | 结局 |
|---|---|---|
| 做事派 | 不配置直接派活，靠任务次数进步 | 天花板低，永远是"打杂助理" |
| 养虾派（当前主流） | 一点点磨合攒规则→存原则→写文件 | 慢、孤立——复制一个新专家要从头来过（"相当于从大学毕业生一点点带，而不是直接招 5 年老手"） |
| 训虾派 | 复杂工作流 + 专业体系集中集训 | 批量产出 Top 级角色 |

- 诊断句："调教失败不是 AI 的问题，是使用姿势搞错了"；"成年人只能筛选，不能培养——为什么到了 AI 时代大家就喜欢'养'？"
- **与本仓库的张力及裁决**：CLAUDE.md / 周度蒸馏本质是养虾派渐进积累。裁决：**唯一长期分身用"养"（沉淀唯一、不可复制），批量造新角色用"训"**——且训的输入源恰恰是养出来的体系（见"三大输入源"①③）。养是复利，训是复利的兑现。

## IPO 模型（角色的生产线）

```
高价值信息 INPUT（三大输入源）→ 处理/建模 PROCESS → 角色配置文档 OUTPUT（1000~3000 字，5~7 个文档）
```

- 关键推论：**文档配置水平 = 角色一切能力的上限**（沟通、表达、思考、专业方法、做事文化全取决于那几个文档）。
- 既然 OUTPUT 只是几个文档，就可以在 INPUT/PROCESS 上大量提假设、挨个测——一天天磨出来 vs 一次性拉高水平，**没有本质区别**；省掉的是几周时间，不是质量。

## 双三角模型（人 + AI 各自的做工点）

- **人类侧（必须足够强、不让渡）**：①**审美**——对岗位有判断力、有方法论审美、脑子里有优秀人类员工的参照系；②**体系**——完整 IPO 思路与入门→进阶→高阶框架；③**创造力**——敢提新假设、敢绕开一次次磨合直接集中训练上岗。
- **AI 侧（训练 AI 去做）**：④**基本功**——提示词 / Agent 工具 / 结构化萃取；⑤**数据（最关键养料）**——平台官方文档 + 官方最佳实践 + 雇主/项目介绍数据包；⑥**场景（提高要求）**——不止日常小助理：辅助决策、做"减一层的负责人"（技术/营销/科研负责人）、未来统筹 AI 项目管理。

## 角色生产流水线（可直接抄的步骤）

1. **备三大输入源**：① 关于雇主/项目的高质量系统介绍（使命/工作体系/文化底线/偏好与厌恶清单）；② 平台官方文档体系的审美建模拆解（每个文档：定义 + 配置后有什么用 + 使用技巧，最终合并为顶层指南）；③ 自己对岗位的审美与判断力（工作方式/价值观/方法论/参照的优秀人类案例）。
2. **文档阶梯按生存期配置**：入门必配 运行协议 + 灵魂文档（基因/宪法，最重要）+ 身份定义 → 进阶加 用户理解 + 节律/状态 → 高阶加 工具扩展 + 全局配置。（映射 Claude Code：SKILL.md=运行协议，CLAUDE.md/人格设定=灵魂文档，agent 定义=身份。）
3. **口喷输入法**：只描述 10%——"我想要一个[角色名]，负责[核心职责]，性格是[关键特质]，擅长[核心能力]，我过去见过最好的[类似角色]的样子是……"——AI 补全 90%。**前提是最佳实践框架已做底座**；没有底座的口喷 = 瞎编。（与 [ai-native-coordination](ai-native-coordination.md) 修路节"MD 口喷让 AI 记本体"同词异域：那管业务知识，这管角色规格；两处可叠用。）
4. **演戏法喂文档**：不说"学一下这个文档"（敷衍处理），用角色叙事驱动内化——"咱们合作十几年了，你是我的设计负责人，你赶紧去找记忆吸收一下"——AI 进入"老朋友重逢"模式逐条认真读取。
5. **复杂岗位逐步迭代法**：市场上无标准定义的岗位——从自己知识库抽离整个方法论体系一次性喂给 AI 配置画像，再多轮打磨（换名字/加审美/调风格）。
6. **用真实任务验收**：给角色一个高价值真任务（一堂例：让数字分身"给某产品设计 10 个高价值调研课题"，产出质量超内部员工、报告估值"外部咨询 5 万"）——配置水平的度量是产出，不是感觉。

## 段位评估 + 控制变量对比（角色质量管理）

- **六维加权评分建台账**：灵魂维度 · 用户理解 · 工具能力 · 雇主信息 · 关键记忆 · 工作经验（一堂团队实测分差显著：84 / 70+ / 60+ / 50+ 分梯队）。
- **六个训练触发器**（任一发生即回炉）：有新的职业美好想象 / 新方法论模型 / 新标杆案例 / 更完整资料包 / 新沟通习惯 / 犯错踩坑后——"任何你自己灵光一闪的一次进步，都可能成为 AI 的一次升级"。
- **有/无配置文档对照实验**（控制变量，3 组）：营销角色写口播文案（通用 AI 感强 → 黄金钩子+ABCC 结构自动呈现）；产品角色写 PRD（讲技术实现完全不在线 → 战略定位/商业模式/护城河视角可用）；分身答战略困惑（知识检索式违反直觉 → 方法论范式迁移+交叉验证在线）。**评角色必须 A/B 对照，不能凭印象。**

## 多角色协作：民主集中会议

CEO 助理角色整理近期想法/日程 → 分发给全团队 AI 角色 → 各角色从自己岗位视角发表意见 → 交叉合并、两轮讨论 → 输出优先级排序 → **人做最终决定**。全程无技能、全靠角色配置文档——是 renxin"老板模式"（AI 发散量产、人只挑刺+挑选）的多角色版，也是 [multi-agent-orchestration] 编排时的议事模板。

## 与既有层的关系（裁决）

| 本文章款 | 既有条款 | 裁决 |
|---|---|---|
| 训虾派 vs 养虾派 | CLAUDE.md 渐进沉淀 / 宪法 C0 复利 | 分工不冲突：**养 = 给唯一分身攒复利，训 = 用养出的体系批量复制新角色**；训的输入源①③就是养的产物 |
| 文档 = 能力上限 | 任鑫"母提示词"1500 字入职手册 | 同一判断两种表述：任鑫给单人协作版，训虾派给批量生产版（IPO + 文档阶梯 + 口喷） |
| 口喷输入法 | 任鑫提示词四法"用魔法打败魔法" | 互补：口喷管角色生成（10%→90%，需底座），反问补全管任务执行 |
| 六维段位评估 + 配置 A/B | ai-mastery 纪律 6（verifier > generator） | 同构：造角色与评角色分离；有/无配置对照 = 最小 verifier |
| 民主集中会议 | renxin 私董会智囊团 / multi-agent-orchestration | 同一模式不同规模：单 AI 多视角 vs 多角色各视角 |
