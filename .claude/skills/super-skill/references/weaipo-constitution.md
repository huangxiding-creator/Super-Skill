# We-AIPO 开发宪法（全局适配版）

> 来源：We-AIPO 项目（自媒永动机，双管线全自动内容引擎，290+ commit / 4700+ 守卫测试 / 0902-0907 五轮瓶颈攻坚）交互史沉淀提炼，2026-09-07 用户令「提炼+沉淀」。原则均以通用形式表述；括注为 We-AIPO 实锤事故索引（每条讨厌事项背后都是真实事故，不是偏好）。
> 加载时机：任何长期运行的生产系统（自动化/爬虫/发布/定时任务/多账号操作）的设计、守卫、收线、复盘环节；与 `audit-loop-case-study.md`（过程方法论）、`pai-station-doctrine.md`（价值裁决层）互补，本文件是**无人值守系统的运行宪法**。

## 十二条开发原则

1. **数据不信报表信产物账**——完成判定 = 可对账产物存在（完成标记文件 + 发布记录逐条对账），不是「代码跑完」「日志有输出」「grep 到 print」。观测口径与产物口径分离时，以产物账为准。
2. **改进以真实用户数据为基础**——用已发布内容的真实阅读/互动数据回归出规律再动生成端；反自嗨是纪律：任何「我觉得更好」若无线上数据支撑即不实施。
3. **可以吞异常，绝不吞痕迹**——best-effort 每一口必须留 debug 级日志；全库真静默 except 有预算上限（如 ≤45），新代码超预算即测试红线。吞异常不吞痕迹 = 零阻断与可追溯兼得。
4. **教训固化成守卫测试，钉死才翻篇**——每个事故修完必配守卫测试（源码锚/行为级），否则同型事故必复发；锚随重构走，锚漂移即测试失效（同型漂移已两犯）。
5. **探针语义分离**——放行探针可保守（不确定就放行，别卡死流程）；等待探针必须确证（等到了才算到，保守 True = 门恒不触发 = 等待门失效）。用错语义的门比没门更危险。
6. **单径法，永远不要降级路径**——done 是唯一放行条件；skip/absent/降级输出 = 失败被合法藏匿的仓库。降级路径今天救一次上线，明天静默吞一次全灭。
7. **一切无界皆事故**——重试必有界、等待必有 deadline、grace 窗 ≥ 物理上界（就绪要 151s 就给 ≥151s，差 1s 就是事故）；timeout 旗标会杀合法慢任务，设前先测真实耗时分布。
8. **站在成熟库肩上，自研只做薄适配层**——生产级稳定功臣永远是成熟现成库；逆向自研协议层是 bug 窝。新增外部交互第一动作 = 找顶级开源库，能用必用。
9. **用户主权红线由用户定义**——广告内容/用户桌面应用/网络出口/用户手改之物，技术可行 ≠ 可以做；清单只能用户扩，不能自动化绕。
10. **人工前置集中一次，之后全程全自动**——把人工（确认/授权/扫码）压缩到启动第一个窗口内集中完成，之后给用户「可离开信号」；零请示：遇问题自己截图分析自己修，不打断用户。
11. **跑中不改码，改码必在跑前**——实施窗与运行窗分离；定时任务必须执行最新已提交代码；改码后跑的若是旧代码，等于没改还骗了自己。
12. **螺旋闭环：复盘→提案→实施→观察点→数据回流**——缺一环即自嗨；复盘改进项必须挂主链不挂旁路，否则下轮发现根本没跑。

## 十二条最讨厌（发现立刻叫停）

- **假完成假账**——草稿 14/群发 0 仍报成功；skip 假放行；对账数字对不上仍收线。
- **误判零容忍**——判卡死/判失败前必验三源（正确日志文件 + mtime + 进程命令行）；健康主线被当僵尸强杀、配额数字读错字段，都是真实事故。
- **请示打断**——零请示族；用户手动操作场景必须停自动化等待，绝不轮询催。
- **静默失败**——import 错误被吞 = 三个月零采集；进程静默死亡无人知；观测口径用 grep print 而非产物账。
- **抢占打扰**——没必要不抢鼠标；禁止操作用户桌面应用；用户活跃期窗口让位；授权弹窗时机错（全做完了还弹）。
- **误导告警**——代码 bug 被告成「平台问题/系统问题」，用户白查白点；告警必须带真实根因与 repr，绝不发空 error。
- **跑旧代码**——绝不用旧端点旧代码，发现即删；废弃组件杜绝启动。
- **降级半途换通过**——优雅跳过掩盖失败；质量标准不降低（低通过率是设计意图不是 bug）。
- **动用户的东西**——用户手改的内容绝不修改覆盖，不加点不加改；注入/发布/再生成全绕开。
- **不彻底**——战场没收干净（进程树/系统级劫持/陈年文件三漏网）；收线必查进程、文件、网络、缓存四线。
- **自研轮子**——成熟库已有解还手搓；新增外部交互不调研直接写。
- **无界空转与僵尸残留**——33 分钟无界重试；僵尸进程反复作乱；孤儿进程；收线残留劫持。

## 开发宪法（冲突裁决序）

```
用户主权与账号安全 > 真话不误导 > 产物账完成 > 运行效率 > 功能新增
```

遇到原则冲突按此序裁决，每次裁决在复盘账本记一行（何冲突、何取舍、为何）。
- 用户主权与账号安全永远第一：封号一次全盘归零，效率永远建立在账号安全地基上。
- 真话第二：宁可报「失败 0 产出」也不报假成功——信任崩一次，所有后续通报贬值。
- 产物账完成第三：1:1 全链等比（输入:中间产物:终产物）是完成定义，不是努力定义。
- 效率第四：提速手段触碰前三条（防封间隔/服务器/违令提前）即停，需用户裁决。
