# Radar 2026-10-01 — V5.1.1

**Summary:** 新增第三方 skill 安装前安全审查（engine/skill_vet.py），find-skills 自动安装前必须通过 CLEAN/LOW 判定，堵住 Phase 2b 未审查直接 `npx skills add -g -y` 的供应链风险。

## Adopted
- **NVIDIA/SkillSpector** — Pre-install static vetting of agent skills: rule categories (prompt injection, exfiltration, supply chain, dangerous code, hidden triggers), 0-100 risk score with severity levels, fail-closed scan bounds, rule suppression; wired as a gate before find-skills auto-install → `engine/skill_vet.py, engine/tests/test_skill_vet.py, skills/find-skills/SKILL.md` (Apache-2.0, pattern)

## Reviewed, not adopted
- mksglu/context-mode: Licence is Elastic License 2.0 (README badge; GitHub reports NOASSERTION), so pattern-only at most; the idea of keeping raw tool output out of context overlaps the existing context-compressor/context-management sub-skills.
- rohitg00/pro-workflow: MIT; correction→rule memory plus an FTS5 wiki duplicates the existing ACE playbook (`ss playbook`) and the FTS5 `ss mem` index.
- Q00/ouroboros: Not reviewed in depth this run (budget); deferred.
- FlorianBruniaux/claude-code-ultimate-guide: Guide content under CC-BY-SA-4.0 (share-alike); not reviewed in depth, nothing specific identified to adopt.
- ruvnet/ruflo: Large multi-agent framework; not reviewed in depth, no small adoptable change identified.
- athola/claude-night-market: Not reviewed in depth this run.
- Gentleman-Programming/gentle-ai: Not reviewed in depth this run.
- WenyuChiou/awesome-agentic-ai-zh: Curated list, not a source of directly adoptable mechanisms.
- jmagly/aiwg: Not reviewed in depth this run.

## Files changed
- `engine/skill_vet.py` — Stdlib static pre-install vetting for third-party skills: 12 rules (prompt injection, exfiltration, obfuscated exec, curl|sh, destructive, persistence, agent-config tampering, blanket permissions, hidden unicode), 0-100 score, fail-closed bounds, --ignore suppression, exit 1 at/above --fail-on
- `engine/tests/test_skill_vet.py` — Tests for skill_vet: clean, injection, exfil/obfuscation, hidden unicode, skip dirs, suppression, per-rule score cap, fail-closed bounds, CLI exit codes and JSON
- `skills/find-skills/SKILL.md` — Phase 2b auto-install (npx skills add -g -y) now requires a skill_vet verdict of CLEAN/LOW; MEDIUM goes to manual review, HIGH/CRITICAL is rejected; gate check + report record the verdict
