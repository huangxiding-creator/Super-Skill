## 一句话总纲

桌研用**思维密集度**选源、**五本书梯度**爬阶、**强力研读**榨干、到**交叉点前沿**形成观点；田野用**六步程序 5W1H** 控质量、**访谈信任**换真话、**报告五步**收口——调研的终点不是"知道了什么"，而是"能给出什么思想 / 结论"。

## 一、桌研（万维钢）

### 世界观五公理（方法的根）

1. **脑力工作统一论**：一切脑力工作 = 吸收大量信息→头脑中化学反应→创造新信息；调研不是写作的前置工序，是工作本体。
2. **只读活人的书**：知识快速迭代，任何"名著"都是可被淘汰的假说（卡尼曼多个结论已被新研究推翻）；经典理论会被新书反复提及，无需读原文。
3. **思维密集度 = 准备这份读物所需总时间 ÷ 阅读它所需时间**：好书几百、博客几十——调研的性价比本质是"用几小时兑现别人几千小时的准备"。
4. **以新研究为本**，反"名人经典"路线（选英文新研究综述，不选传统人文名著）。
5. **思想 > 知识**：把读者当服务对象（有用的知识+有趣的思想），不当宣传对象，更不卖弄。

### 六环节工作流

1. **选题 = 敏感度 × 系统**：敏感度（豌豆公主——二十层床垫下一粒豌豆；赫拉利"知识 = 体验 × 敏感度"）可刻意练习；把调研当**系统**（定期做、当研发平台测试话题类型），"建立大系统者不纠结"，完成比完美重要。
2. **输入纪律**：固定高质量信源清单（原清单为英文刊物与作者博客；对应 AI 开发：官方文档 / changelog / 一手工程博客 / 论文库优先于转述媒体）；**五本书梯度**——①通俗畅销书建基本盘 ②热门书记下最激发想象力的细节 ③专家视角书建大局观 ④硬书（专家写给专家）识别当前专家最感兴趣的话题 ⑤未来走向书感知前沿；读书抓三点：**领域历史叙事（主要矛盾）、行话术语、让自己兴奋的东西**——"高手学习一定是以我为主，建立属于自己的技术基线"。
3. **强力研读（核心手艺）**：三原则"不好玩、用时少、不追求快"；**读两遍只读两遍**——第一遍陷进去（作者怎么说），第二遍跳出来（理性评判）；笔记四标准：①清晰呈现每章逻辑脉络 ②带走所有亮点 ③大量自己的看法 ④与其它书/文章的联系；**笔记写到可以取代原书的程度**（思维导图无用——只有方面、没有方面之间的连接）；【】方括号放自己的评论。
4. **外部存储（对抗人脑短板）**：人脑擅长识别不擅长提取（列不出所有美女但一眼认出美女）→ 专注识别、让系统提取；**"想法立项"先占位**，遇到素材就挂链接，一个选题攒几十条素材几年后才动笔；笔记互链让算法帮你发现"你自己忘了的三件事"——"记下来了，你就不用惦记它了"（解放大脑去想事，不作存储器）。
5. **调研式学习五步法**：读书 → 采访专家（先做家庭作业，"你的问题，你得负责"；专家只精通自己课题——问国米左后卫"世界足球发展"=白问）→ **到达前沿**（前沿 = 教科书空白、无公认答案处，常在**不同领域的交叉点**；"最有争议的地方恰恰最活跃，可能就是你的机遇所在"）→ 形成观点（敢支持敢反对；观点允许几次反转，没反转可能思维不够积极，但不能人云亦云）→ 完成叙事（把新观点讲成故事、理顺因果；费曼检验讲给家人/陌生人；**找专家审稿**）。
6. **输出三原则**：focus（心里只对一个说话对象）· wit（雅致的幽默）· polish（修改，修改，再修改——好文章是改出来的）。

### 思维模型件（判断信息时调用）

| 模型 | 调研用途 |
|---|---|
| 思维密集度 | 信息源性价比排序 |
| 37% 最优搜集 / 基廷斯算法 | 信息搜集何时停（探索 vs 利用；未来越长越探索） |
| 过度拟合 | "宁要模糊的正确不要精确的错误"——防调研陷入细节沼泽 |
| 学术积木论 | 判断单篇论文 / 单条新闻的实际权重（一块积木等未来拼装） |
| 专家五重境界（新手规则→经验→优先级→整体性→环境） | 评估"专家"段位——采访对象分级 |
| 律师机制 / 确认偏误 | 审查信源的论证方向（先有结论再找证据的排除） |
| tradeoff 取舍 | 兴一利必生一弊——拒绝"不惜一切代价"式抒情 |

### 批判边界（用前必读）

① 输入错误输出必错——流程不豁免信源核查，反而更依赖；② 英文新出版世界同温层盲区（对非英语原创研究覆盖弱）；③ 律师机制反身性——教人防"先有结论再找证据"的方法论拥有者自己也犯；④ 适用域 = 综述型转译创作——**实验与田野段不覆盖**（由下篇补齐）。

## 二、田野（何晓斌）

### 三分类定位

调研分政府 / 企业 / 学术三类主体，探索 / 描述 / 解释三种目的——**AI 产品开发者的调研绝大多数 = 企业类 ×（探索性→描述性）**：把握客户需求偏好与行业现状，为产品研发 / 营销提供依据，特别注重"用数据说话"。

### 六步程序（每步都有交付物）

① **明确目标**（"目标像靶子"——大题目必须细化分解才可执行，否则要么烧钱要么拆子课题）→ ② **计划 5W1H**（为何 / 谁 / 何时 / 什么 / 何处 / 如何；计划不是线性理性的，是专业背景×资源×预算的综合产物）→ ③ **文献与前期准备**（"别人的成果已经相当丰富的，没有必要重复调研一遍"；用二手数据先摸现状）→ ④ **实地调研**（**每天总结整理、比对计划进程**，思考资料能否回答调研问题；适当增加随机访谈从侧面印证正式渠道）→ ⑤ **整理分析**（定性定量分开处理再综合）→ ⑥ **报告**。

### 定性 × 定量（点面结合）

- 定性 = **解剖麻雀**（费孝通）：深入细致、过程化情境化，答"为什么"，适合新现象探索；弱点是个案不代表全体 → 需多案例比较增强代表性。
- 定量 = **望远镜**：去情境化找普遍联系，答"是什么 / 怎么样"；问卷高度标准化利于统计，但难追问内在动机。
- 条件允许一律**混合设计**：先定性探索机制，再定量验证分布——"只用解剖麻雀不够全面，要规定麻雀在全部麻雀中占什么地位，就得定量分析"。

### 访谈关系六原则（真话的交换条件）

尊重保护隐私 · 建立信任互惠 · 事前清晰解释目的 / 内容 / 时间框架 · 知情同意与自主参与 · 主动倾听给表达空间 · 反馈与回报。"很多时候，要先让调研对象了解自己，然后才能调研他——一旦被察觉没有诚意，就再也听不到真心话。"（映射用户访谈：访谈不是提问技巧，是关系工程；一对一面谈最快速建立信任、减少他人在场干扰。）

### 报告五步（立好意 → 定好题 → 理思路 → 搭架子 → 用资料）

1. **立好意**：立意是报告的魂（"文者，意为先"），好立意**明确 · 集中 · 新颖**；两类初学者死法——"下笔千言，离题万里"（分论点没梳理清楚）与"眉毛胡子一把抓"（辛苦调研来的资料舍不得扔，什么都写=什么都没写清楚）；解法只有一个：**聚焦，锁定一个核心问题**组织全部资料。
2. **定好题**：标题交代调研对象 + 主题事由；设问式主标题 + 范围副标题（"流动还是留下？——某地区流动人口的迁居调查"）比描述式吸引人；文字简短——冗长标题暴露概括能力不足。
3. **理思路**：对资料去粗取精 / 去伪存真 / 由此及彼 / 由表及里后形成组织主线（先想清楚建什么风格的"房子"）。
4. **搭架子**：先定报告类型，再定"四梁八柱"（一 / 二 / 三级标题树）；两个高频错误——**不分主次**（次要内容占了承重墙位置，楼会塌）与**资料错用**（好资料放错位置反伤论证）。
5. **用资料三原则**：**精**（只选与主题框架密切相关的，熟谙资料后反复归纳比较筛选）· **准**（来源可查——标注时间地点与出处；一针见血说明论点）· **新**（量化数据用最新、定性用一手）。
- 政府类报告骨架"**是什么—为什么—怎么办**"同样适配企业调研报告与产品分析报告。

## 三、双源合璧（AI 产品开发者的调研闭环）

桌研定方向（五本书梯度 + 前沿交叉点找机会窗口）→ 田野验真伪（访谈 + 问卷识别伪需求、验证 JTBD）→ 报告收口（立意—架子—资料）。两源共享一条铁律：**你的问题你负责**（万维钢：采访前做足家庭作业，把专家水平用到刀刃上；何晓斌：目标明确才配得上资源）。

## 四、落地映射（super-skill 场景）

- **research-orchestrator**：9 渠道检索结果按"思维密集度"排序与去重；源类型按"五本书梯度"分层（官方文档 / 源码 = 硬书层，转述媒体 / 公众号 = 畅销书层——硬书层结论优先）。
- **Phase 1 可行性 / 竞品分析**：先用"学术积木论 + 律师机制"审信源权重与论证方向，再入 `FEASIBILITY_REPORT.md`（对应宪法 C14：不编造数据、区分材料与推断）。
- **RESEARCH_DIGEST / proposal 写作**：按"立意—标题—架子—资料"四步收口；用资料三原则（精准新）做引用把关。
- **用户访谈（需求验证）**：访谈关系六原则 + 一对一面谈 + 定性探索→定量验证的混合顺序。
